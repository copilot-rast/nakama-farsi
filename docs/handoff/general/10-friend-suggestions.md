سرور هر روز (روز پروژه) برای هر بازیکن یک فهرست پیشنهاد دوستی می‌سازد. منبع‌ها به ترتیب: کسانی که اخیراً با او بازی کرده‌اند، دوستانِ دوستان، بازیکنانی با فعالیت مشابه و (اگر ادمین جدول سطح را انتخاب کند) سطح مشابه. دوستان فعلی، درخواست‌های باز، بلاک‌ها و کسی که امروز درخواستش را رد کرده در فهرست نمی‌آیند.

## فهرست

```text
base_friend_suggestions
```

بدنه: `{}`

```json
{
  "enabled": true,
  "cycle": "2026-11-21",
  "refreshesAt": "2026-11-21T20:30:00Z",
  "suggestions": [
    {
      "userId": "<user id>",
      "username": "bita",
      "displayName": "بیتا",
      "avatarUrl": "",
      "code": "K7Q2ZD",
      "online": true,
      "source": "coplay",
      "mutual": 0,
      "lastPlayedAt": "2026-11-21T09:14:03Z"
    }
  ]
}
```

| فیلد | معنی |
| --- | --- |
| `source` | `coplay` (هم‌بازی)، `mutual` (دوست مشترک)، `activity` یا `level`. برای متن کوتاه زیر نام: «با هم بازی کردید»، «۳ دوست مشترک» |
| `mutual` | تعداد دوستان مشترک |
| `lastPlayedAt` | فقط برای هم‌بازی‌ها |
| `refreshesAt` | فهرست بعد از این زمان تازه می‌شود |

اندازهٔ فهرست را ادمین تعیین می‌کند (پیش‌فرض ۵۰، با ۲۰ ذخیره). `enabled: false` یعنی بخش را نشان ندهید.

## رفتار

* فرستادن درخواست دوستی (`base_friends_add` یا `AddFriends`) آن بازیکن را از فهرست هر دو طرف برمی‌دارد و اولین ذخیره جایش می‌آید. لازم نیست فهرست را دوباره بگیرید؛ بازیکن را از فهرست محلی حذف کنید.
* بعد از پایان هر مسابقه در کاتالوگ بازی‌ها، هم‌بازی‌ها چند ثانیه بعد بالای فهرست همان روز می‌آیند.
* کسی که چند روز پشت سر هم در فهرست دیده شده کم‌کم پایین‌تر می‌رود.
* فهرست را با هر باز شدن صفحه بگیرید؛ ساخت فهرست روزی یک بار است و تکرار درخواست هزینه‌ای ندارد.
